三、功能覆盖

解析层次

  • pcap（大小端自动识别）/ pcapng，链路类型 EN10MB
  • Ethernet、ARP、IPv4、IPv6（扩展头链、分片重组）
  • TCP、UDP、SCTP（chunk/PPID）、ESP（仅头）、NAT-T
  • GTP-U（G-PDU 内层拆解 + 按 TEID 合并）、GTPv2-C

输出能力

  • 统计报告：协议分布、Top 端口、流、TCP flags、SCTP chunk
  • ESP SPI 分布（序列号回退标注「疑似重放/乱序」）
  • GTP-U TEID 合并：包数、合并量、截断、序列号范围、内层流
  • 载荷 dump：hex/str/both，可配 --dump-bytes
  • JSON：packets / gtp_tunnels / 聚合统计

六、运行方式

python test\scripts\run_all.py                  # 一键回归：7 模块 498 例，约 13s
python test\scripts\run_all.py --mutation dump  # 追加 dump 组变异扫描
python test\scripts\run_all.py --mutation core  # 追加 core 组（约 3 分钟）
python test\scripts\mutation_dump.py --list     # 查看变异清单
python test\scripts\mutation_dump.py --target pcap_analyzer.py `
    --tests test_gtp,test_esp --spec my_mutants.json   # 自定义目标与清单

退出码：0 全部通过；1 存在失败；2 基线用例失败。

七、已知限制

  • ESP 只解析头：SPI、序列号可读；Padding / Next Header / ICV 位于加密域，密文按原样 dump，需密钥解密。
  • 不做通用 TCP 全流重组：仅 DNS 的 2 字节长度前缀流，其余应用层按包级特征识别。
  • 资源上限：流数、单流字节数、空闲超时受常量约束，超限流被淘汰并计入资源统计。
